# Drop Stats

This folder contains generated or manually maintained summaries of observed DaddyStitch drop data.

Important: these are **observed field frequencies**, not global drop rates.

A sample of one kill with one drop should be treated as one field observation, not as proof that the item always drops.

Suggested structure:

```text
generated/drop-stats/mobs/<mob-slug>.json
```

Each mob file can track:

- observed kill count
- observed drop count per item
- observed frequency
- related event IDs
- last updated date
