# Trade Items Index

Trade items are stackable or economy/crafting-relevant items such as leather, hides, cloth, ore, herbs, meat, fish, thread, and similar materials.

Use this category for items that are primarily useful because they can be crafted with, sold, cooked, gathered, skinned, or traded.

## Data Rules

Trade item pages should include:

- observed source
- drop or gathering method
- vendor value, if observed
- purchase price, if observed
- AH value, if observed
- crafting uses, if observed
- quest uses, if observed

Do not invent source or pricing data. Mark external reference data separately from personally verified DaddyStitch data.
