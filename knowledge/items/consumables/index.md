# Consumables Index

Consumables are items that are used up when consumed, applied, eaten, drunk, read, or activated.

## Types

- [Food](food/index.md)
- [Drink](drink/index.md)
- [Potions](potions/index.md)
- [Bandages](bandages/index.md)
- [Scrolls](scrolls/index.md)
- [Elixirs](elixirs/index.md)
- [Other](other/index.md)

## Data Rules

Consumable pages should include:

- observed source
- use/effect, if observed
- vendor value, if observed
- purchase price, if observed
- crafting recipe, if observed
- quest relation, if observed
- Hardcore usefulness notes, if personally observed

Do not invent use effects or prices. Mark external reference data separately from personally verified DaddyStitch data.
