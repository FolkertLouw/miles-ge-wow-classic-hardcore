## Data Rules

Gear pages should include:

- item name
- quality
- armor or weapon class
- slot
- stats, if observed
- armor value, if observed
- source type
- source quest, mob, vendor, or craft
- whether DaddyStitch can use it now, if known
- vendor or AH value, if observed
